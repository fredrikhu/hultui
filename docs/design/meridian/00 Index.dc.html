DECISIONS RECORD
· Identity: Azimuth — cyan on blue-black, compact, squared solid-tint chips (picked over Isobar, Antipode)
· Response pane right by default, Ctrl+\ flips, auto-bottom < 1100dip — both mocked
· Navigation: Junction idiom — slim view rail (keys 1–5), tree lives inside Requests
· Discovery is view 3 on the rail, promote-to-collection bridge
· Sample content: fictional payments API · key glyphs: Ctrl (Win/Linux)
· No WebSocket/SSE/gRPC stubs; URL bar leaves room for a future protocol picker
READING THE MOCKS
· Numbered cyan dots on frames → legend under each frame with token names + dip values
· Every mock lists its active key bindings bottom-right
· Pass/fail/skip always carry glyphs ✓ ✗ − — color is never the only signal
· File paths shown in mono everywhere the disk is the source of truth
· Runner summary visually matches the CLI/JUnit report — annotated in §04
