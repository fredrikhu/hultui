TOKEN SHEET — Theme/Azimuth.cs REGISTER
Dark-first, one accent, everything named. Sibling to Nocturne (Vesper) and Swatch (Junction): same register shape, its own personality — cool cyan, compact rows, squared corners, mono wherever the data is technical.

STATUS REGISTER az-status-*
✓ pass az-status-pass #4FBE7E 2xx, assertion pass
✗ fail az-status-fail #E5636B 5xx, assertion fail
! warn az-status-warn #E8C14A 4xx, unresolved var, infra
− skip az-status-skip #8A99AC skipped, 3xx muted
The glyph trio ✓ ✗ − survives CI grep and screen readers; warn adds ! . Infra failures (DNS, refused, timeout) are warn, never fail — a failed assertion and an unreachable host must not share a color.
