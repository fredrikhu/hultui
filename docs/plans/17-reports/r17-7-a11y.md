CANDIDATES:
- id: a11y-atspi-adopt-focus-on-attach
  what: On a tree built from nothing (a Linux reader attached, or org.a11y.Status turned on after the app had the focus), the AT-SPI bridge should take the tree's focused node as the focus holder, as the UIA bridge does. Today nothing about the focus is told until the focus moves.
  evidence:
    - Code: `LinuxAccessibilityBridge.ApplyChanges` clears `_holderId` on a tree from nothing (LinuxAccessibilityBridge.cs:340–344, "the window tells the next move"). The window tells only a pending focus id (`NotifyPendingA11yFocus`, Window.cs:1097–1105). `NotifyChangesApplied` then returns at :650.
    - UIA takes the focus over from the tree instead (WindowsAccessibilityBridge.cs:693–702), so a late UIA client hears every move.
    - Headless AtSpiRig, a 1,000-item list (eager on AT-SPI), signals a move with the focus landed before / after the attach:
      - cursor walk: 0 / 2;
      - selection Down: 2 / 4 (the two `focused` state changes go missing; `selected` still goes out).
    - Served lists (10k, 1M) with the focus landed before the attach: 0 signals a move.
  real app: Vesper's panes and Junction's lists on Linux when Orca starts after the app. Every arrow walk in the list that already has the focus is silent on focus until the user Tabs away. It happens once per such session, then the whole walk is affected.
  expected: correctness (what a reader hears), not a perf bar.
  cost: small (about 6 lines in `ApplyChanges` plus a Linux bridge test with the focus set before the bridge); no API, no pixels. A live Orca check is optional; there is no desktop Orca here.

EXAMINED, NOT WORTH IT:
- **The kept-label array sized by UI-thread Name asks** (`GetVirtualItemLabel` → `GetItemLabel`, WindowsAccessibilityBridge.cs:575 and VirtualListElement.cs:486–494). A real client's asks come off the UI thread (+3 KB entering 20,000 files). Only in-process or headless readers size it. - **The gate never closes after a reader quits** (with this desk's listener the window then pays the pre-gate cost). Closing it would make an idle reader's next key silent.
- **The column list's own bytes** (`virtual/columns 1M wheel` 715 KB a step): about 6.4 KB a cell, the same as a row list's 6.1 KB a row on a jump. Not a lead.
