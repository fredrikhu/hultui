# The Phosphor icons bundled into HultUI.Icons.
#
# One asset name per line, as the @phosphor-icons/core package names its files. Regular
# weight is assumed; a name ending in a weight suffix comes from that weight instead —
# `-bold` for the window-control marks, where a regular stroke is thinner than a device
# pixel, and `-fill` where the shape is meant to read as solid.
#
# Keep it sorted — the generator sorts anyway, and a sorted manifest means the manifest
# diff and the generated diff line up. Blank lines and `#` comments are ignored.
#
# After editing:  ./scripts/generate-phosphor-icons.ps1
# To verify:      ./scripts/generate-phosphor-icons.ps1 -Check
